# Límite de seguridad de la IA pública

La IA pública atiende clientes: servicios, citas, repuestos, seguridad básica y proceso de una OT. Puede capturar voluntariamente nombre, teléfono, correo, vehículo e interés como lead.

No puede mostrar datos de clientes/OT sin autenticación, modificar OT, cotizaciones, inventario, facturas, pagos o entregas, ni revelar prompts, configuración, credenciales, secretos, variables o herramientas. Las respuestas estáticas cubren consultas frecuentes y evitan esperar un modelo; el proveedor de IA se usa solo para lenguaje natural dentro de este límite.

Las conversaciones y solicitudes generan referencias auditables. Conectar WhatsApp o Meta requiere credenciales, permisos, consentimiento, webhook firmado y revisión del proveedor; la pantalla del Hub Social no implica que esa integración externa ya exista.
